# 「PLATEAU AI アシスタント」の概要

「PLATEAU に相談」とは、国土交通データプラットフォーム（MLIT DPF）にあるPLATEAUのデータを活用するための会話型チャット サービスを指します。自然言語で質問し、回答を得たり、地理空間データの特定や空間クエリを実行したりできます。

## 主な機能

この初期バージョンは、都市計画家、建築家、エンジニアなどの専門家や非専門家をサポートするように設計されています。国土交通省の豊富なオープンデータを使用して、空間パターンと機会を探索できます。

主な機能は次のとおりです。

1. **Search系 (複数対象・範囲検索 / Multi-Entity Spatial Search)**:
   - **データセット**（`bldg` 建築物モデル、`fld` 洪水浸水想定区域、`urf` 都市計画決定情報など）、**施設・建築物**（LOD2 モデル、避難施設等）、および**住所・地名**を対象とした、半径近接検索、バウンディングボックス（空間範囲）検索、キーワード検索、属性フィルタリングを動的マップおよびカード描画とともに実行します。
2. **Get系 (詳細・データ取得系 / Deep-Dive Data Retrieval)**:
   - 施設やインフラの詳細仕様、メタデータ要約、3Dモデル直接ダウンロード（CityGML / 3D Tiles）、ZIP アーカイブ、サムネイルプレビュー、地域メッシュ単位データ、および行政コード正規化情報を取得します。
3. **統合系 (自律エージェント・探索＆深掘り / Autonomous Synthesis & Reasoning)**:
   - マクロなデータセット探索からミクロな個別施設スペックの深掘りまで、空間探索パイプライン全体を自律的にオーケストレーションし、OGC 準拠の 3D 空間インテリジェンス（立地適性評価、制約・リスク分析、3Dシミュレーション）を生成します。

## 主要な特徴：3つの価値の柱

1. **多言語対応（グローバル＆インクルーシブなアクセス / Multilingual）**:
   - 入力言語（英語、日本語など）を自動検出し、言語の壁を解消しながらバイリンガルな A2UI カードと OGC 準拠の空間インサイトを動的に生成します。
2. **事実性（公的オープンデータに基づく信頼のグラウンディング / Factuality）**:
   - 国土交通データプラットフォーム（MLIT DPF）および Project PLATEAU の公式オープンデータ（LOD1/LOD2 3D都市モデル、法定ハザード情報、国土地理院地図）に厳格にグラウンディングし、ハルシネーションのない信頼性の高い空間インテリジェンスを提供します。
3. **推論力（空間・意図の高度なロジック / Reasoning）**:
   - ユーザーの自然な対話の目的を解釈し、多層的な空間分析と実践的な 3D デジタルツインシミュレーションへと変換する高度な空間推論を実行します。

## 制限事項

PLATEAU の Gemini 機能には、次の制限事項と設計判断があります。

- **PlateauView 3D の多言語対応とディープリンク**:
  - **多言語非対応**: 公式の [PlateauView 3D](https://plateauview.mlit.go.jp/) プラットフォームは現在日本語のみで提供されています。英語など他言語で問い合わせが行われた場合、エージェントは 3D モデル検索を円滑に行えるよう、公式の正確な日本語住所・検索キーワードを自動的に括弧書きで付記します（例: `(Search with "埼玉県さいたま市浦和区常盤6-4-4")`）。
  - **URL クエリパラメータ非対応**: PlateauView 3D は現在 URL クエリ文字列による直接の座標パラメータ指定に対応していないため、エージェントはトップポータルへのリンクを案内するとともに、ユーザーに対して正確な検索キーワードを提示します。
