# Agent Skills

Agent skills for the MLIT Data Platform (DPF) agent, compatible with [Agent Skills / Agent Plugins](https://agent-plugins.org).

## Skills

| Skill | Description |
|---|---|
| [`adk`](./adk/SKILL.md) | Guide for using the built-in `google_maps_grounding` tool in Google ADK |
| [`mlit-data-plathome`](./mlit-data-plathome/SKILL.md) | MCP connection and tool reference (`search`, `get_data`) for `mlit-dpf-mcp` |

## Structure

Each skill directory contains a `SKILL.md` file specifying YAML frontmatter metadata and usage instructions.
